## DSC 1.1.14 — Fix Interrupted Bulk Migrations

Fixes an issue where bulk migration in large Tom's Simple Storage networks could stop before finishing, requiring repeated attempts even when the destination still had room. Networks with many empty slots were especially affected.

### Fixes

- Fixed normal Fabric sided-inventory wrapper replacement being mistaken for a network topology change during Tom's periodic rebuilds.
- Compare the underlying inventory slots and access direction, and recognize equivalent transparent double-chest containers, while retaining conservative handling for unknown storage wrappers.
- Keep migration source handles alive for the lifetime of the job so equivalent wrapper replacement does not interrupt an ongoing scan.
- Preserve the default 128-view-per-tick scan budget, including empty slots, transactional rollback, and safety checks for actual endpoint changes and unloads.

### Validation

- Added migration regressions with 3,000, 10,000, and 20,001 slots using real Fabric sided-inventory wrappers and simulated periodic rebuilds.
- The 20,001-slot case completed in 157 migration ticks across seven rebuilds, with item conservation and a maximum of 128 scanned views per tick.
- Added coverage for changed access directions, exposed slot sets, endpoint additions/removals, double-chest replacement, and partial-insertion rollback; retained unload and duplicate-target regressions.
- Passed the build, complete built-in self-test, integration diagnostics, and standalone server verification using the final release JAR, including normal shutdown saving. Client verification was confirmed by the maintainer.
