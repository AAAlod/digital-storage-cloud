## DSC 1.1.14 — Bulk Migration Fix

Fixes an issue where large storage networks could stop migrating partway through, requiring repeated clicks even when there was still room in the destination. Networks with many empty slots were especially affected.

- Fixed bulk migration stopping when Tom's Simple Storage refreshed equivalent sided-inventory wrappers or transparent double-chest containers.
- Large migrations can continue across normal network refreshes while keeping the default per-tick scan limit, including empty slots.
- Preserved safe stopping when the actual network changes and full rollback when a transfer cannot complete.
- Verified migration with more than 20,000 slots across repeated refreshes, with no item loss or duplication in the regression test.
